## 今の Reader の扱い（変更前、main f8f438d）

- 表示の正規化 `normalizeAozoraTextForLayout` は `ここから…`・`ここで…終わり`・`地から…`・改ページなどだけを消す。ほかの注記は文字のまま表示されていた。
- ルビは `renderTextWithAozoraRuby` で `<ruby>` になっていた。
- 文・節の分け方（`splitIntoTrackingSentenceUnits`、`splitSentenceIntoDisplayClauses`、翻訳の `segmentSourceDocument`）は `」` や `、` の後で切るため、`［＃「すゝき」に傍点］` のような注記が2〜3個の表示単位に分かれていた。外字の注記は `、` で切られ、ルビの読みが次の単位に離れることもあった。

## 方針（表示だけ・狭く・戻せる）

保存されている本文、文の分け方、文の番号（録音・しおり・翻訳の対応に使う）は変えない。変えるのは画面の描画だけ。認識できない形は文字のまま残す（消さない）。

| 種類 | 方針 | 実装 |
|---|---|---|
| ルビ | `<ruby>` で表示（従来どおり） | 注記の中の `《》` は注の文字として残す |
| 傍点 | 圏点（`text-emphasis: filled sesame`）。注記の直前の文字が対象と完全に一致するときだけ | `data-aozora-emphasis` |
| 外字 | 確かめた表の字に置き換え、`title` に説明と JIS X 0213 の面区点を出す。表に無い・説明が合わないときは文字のまま | 表は4字：1-7-84 ヹ U+30F9、1-14-88 咜 U+549C、1-88-85 睜 U+775C、2-88-74 譃 U+8B43（Python の `euc_jisx0213` で照合） |
| 異本注 | 消さずに、小さな灰色の注 `〔注：…〕` として本文の中に出す | `<small data-aozora-note="edition_variant">` |
| ルビ注（ママ） | 同上 | `data-aozora-note="ruby_note"` |
| 地より字上げ | その行を右寄せ | `data-aozora-layout="align-end"` |
| 字下げ・小さな文字の範囲 | 対応しない（従来どおり指示だけ消し、本文は通常の段落）。範囲の段落を特定するには段落の作り方に手を入れる必要があり、文の番号への影響を避けて後回し | — |
| くの字点 | 対応しない（`／＼` のまま）。`〳〵` に置き換えるかは S3 の判断 | — |

分かれた注記は、描画のときだけ始まった単位にまとめる（`rebalanceAozoraDirectivesAcrossUnits`）。単位の数とつないだ文字列は変わらない。外字がルビの親字のときは、その読み `《…》` も同じ単位に寄せる。

適用先：原文モード（`WebSpeechEpisodePlayback`）、対訳モードの原文側（`BilingualPane`）。翻訳モードは訳文だけなので変更なし。AI と Human は情報源の選択のままで、4つ目のモードは足していない。`read-test` の `EpisodePlayback` は新しい描画を使うが、分かれた注記をまとめる処理は入れていない。
