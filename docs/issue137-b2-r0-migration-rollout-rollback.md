## Recovery policy (do not confuse the two types of rollback)
| Failure boundary | Safe response | Prohibited shortcut |
| --- | --- | --- |
| Candidate DDL fails before COMMIT, or preflight rejects collision | Database transaction ROLLBACK, re-read installed catalog and stop | Mark migration applied or force repair |
| Post-commit R18/PRIVATE guard causes outage | Fail closed, keep private bucket and restrictive RLS; prepare separately reviewed forward corrective migration and rollback-compatible app | Drop restrictive RLS or flip bucket public |
| Emergency PRIVATE+R18 DB update commits but cache refresh fails | Keep DB PRIVATE, record open incident, verify anonymous Work/Reader/Search and invalidate under explicit operational permission | Claim transaction rolled back or media URL revoked |
| Copy backup fails or bytes do not match | Stop exact-object retirement, keep work private, reconcile digest and private restore | Delete original before backup verified |
| Storage API remove partially fails or old URL/CDN still serves | Keep object-level manifest and incident OPEN; investigate signed URLs, CDN TTL and byte-backed private restore | Raw SQL delete from storage.objects, mass delete, automatic republish |
| Signed-out or other user unexpectedly reads R18/PRIVATE content | Security FAIL/HOLD. Preserve evidence, stop release and independently correct permissions | Weaken test to get a green CI |

Transaction-scoped local rollback rehearsal: scripts/issue137-b2/r0-b2-local-transactional-revert-smoke.sql requires a sentinel present only in synthetic fixture, temporarily removes one R18 policy and one source transition trigger inside a transaction, then issues ROLLBACK and verifies restoration. It does NOT prove reversal of a committed hosted migration or DB+Storage disaster recovery. After any committed high-risk security migration the default is forward-only repair retaining protections, not a blind uninstall. A full approved restore requires DB snapshot plus Storage *physical bytes* and a tested access-control restore.
