# 青空文庫の取り込み（2026-11 バッチ、44作品・410話）

オーナーの指示（2026-11-15）「それぞれの国での無料公開可能な作品をできる限り導入して」に基づく。

## 選び方
- 候補：`npm run public-domain:aozora-candidates -- --limit=100 --per-author-limit=3 --min-chars=3000 --max-death-year=1945`
  - 青空文庫の著作権フラグが「なし」、作者だけ（翻訳者・編者なし）、没年1945年以前、初出1930年以前。
- 100件の候補から、読み物として向く小説・詩歌・戯曲の45件を選んだ。その後、独立レビューで「月に吠える」に室生犀星（1962年没）の跋文が入っていると分かり、このバッチから外した（国ごとの許可リスト方式で別に扱う）。論文・評論・随筆の一部と、長大な連載（大菩薩峠）は外した。
- **国の制限（D030）は不要。**
  - 没年1945年以前の作者は、日本では1996年より前に保護期間が満了しているので、米国でも §104A で回復しない。
  - 死後80年の国でも2025年末までに満了している。メキシコは1952年より前の没者を PD とする。
  - 根拠は `docs/rights/region-research-2026-11-15.md`。

## 章の分け方
- 本文が1万字以下なら1話にした。
- それより長い作品は `paragraph_chunks` で約8,000字ずつ分けた。区切りは文の切れ目で、題は「題名 — Part N」。
- `scripts/public-domain/plan-chapters.ts` で決め、`prepare` で確かめた。

## 内容の注意（content_warnings）
- `scripts/public-domain/content-warnings.ts` が暴力の語の箇所を挙げ、その前後と作品の内容から、Claude が判断した。全文を通読したものではない。
- 判断はオーナーの承認に含める。
- violence は15件、`sexual_r18` は0件。修禅寺物語は独立レビューの指摘で violence を足した。
