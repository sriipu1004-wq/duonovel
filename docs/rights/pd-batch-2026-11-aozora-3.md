# 青空文庫の取り込み（第3バッチ、63作品・282話）

オーナーの指示（2026-11-15）「p9を終わらせるのと、…当サイトで公開可能な作品国ごとの導入を優先順位に導入し、これも完了させて。」と、前の「それぞれの国での無料公開可能な作品をできる限り導入して」に基づく。

## 選び方
- 候補：`npm run public-domain:aozora-candidates -- --limit=100 --per-author-limit=3 --min-chars=3000 --max-death-year=1945`（第2バッチの後に残った100件）。条件は第2バッチと同じ（著作権フラグ「なし」、作者だけ、没年1945年以前、初出1930年以前）。
- 100件から、小説・童話・詩・戯曲の63件を選んだ。論文・評論・随筆の多く、長大な連載（大菩薩峠・泡鳴五部作）、石橋忍月「舞姫」（鴎外の舞姫の評論）は外した。「月に吠える」は室生犀星の跋文を含むので、国ごとの許可リスト方式で別に扱う（`docs/rights/region-research-2026-11-15b.md`）。
- **国の制限（D030）は不要**。根拠は第2バッチと同じ（`docs/rights/pd-batch-2026-11-aozora.md`、`docs/rights/region-research-2026-11-15.md`）。

## 取り込みの前に直したこと
- **冒頭の注記**：第2バッチでは、題・作者の行と【テキスト中に現れる記号について】が本文の頭に入り、取り込んだ後に SQL で消した（#218）。今回から、新しい正規化の方式 `aozora_body` で、取り込む前に保存用の情報（archive metadata）へ移す。注記が無い本文は変えない。注記の後に本文が無ければ止める。既存の `aozora`・`aozora_reader_body` は変えていない。63件すべてで注記が本文から外れたことを確かめた。注記の印があるのに形が合わないときは、取り込みを止める（`AOZORA_BODY_FRONT_MATTER_UNRECOGNIZED`）。
- **外字**：このバッチの本文に出る外字（200か所）のうち、表に無い38の組を `scripts/aozora/gaiji-pairs.tsv` に足し、表を作り直した（155→190種類）。同じ番号で説明の言い回しだけが違う6つ（勹＝つつみがまえ など）は、人が確かめて `scripts/aozora/gaiji-equivalent.tsv` に置き、どの言い回しでも同じ字にする。それ以外の食い違いは、今までどおり字に置き換えない。
