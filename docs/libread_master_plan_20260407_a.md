## 4. 直近の音声系優先順位

### 最優先
**VOICEVOX Nemo 発音辞書MVP**
- 漢字読みミス、固有名詞、当て字、作品固有の読みを修正できるようにする
- 最初は UI なしでもよい
- まずはコード側定義 or JSON 定義で差し込める形にする
- 優先順位は `episode個別 > series共通 > 全体共通`
- 将来 UI を足す前提で、辞書適用関数は分離しておく

### 2位
**VOICEVOX Nemo 本文同期MVP**
- 朗読中に「いま読んでいる箇所」を正しく強調表示できるようにする
- chunk 単位で
  - `text`
  - `start_ms`
  - `end_ms`
  - `paragraphIndex`
  - `chunkIndex`
  を持つ timing 情報を生成
- 生成音声保存時に `recordings` と結びつく timing 情報も保存
- `read` と `EpisodePlayback` 側で現在再生時間に応じて本文ハイライトを切り替える

### 3位
**VOICEVOX Nemo 自動生成トリガーMVP**
- 手動ボタン押下ではなく、作品条件に応じて自動で Nemo 生成を回す
- 朗読無条件許可作品では公開時に自動生成
- 朗読許可制作品では承認時に自動生成
- 生成済み判定、再生成条件、二重生成防止を入れる
- `generation_source`
- `generation_status`
- `generated_at`
- `generation_error`
などの保持を検討する
- 仕様が広がるので、着手時は親チャット再判定前提

### 4位
**VOICEVOX Nemo 間 / 演出微調整MVP**
- 改行
- 連続改行
- 三点リーダ
- ダッシュ
- セリフ閉じ後の地の文
をもう少し演出的に整える
- ただし発音辞書・本文同期よりは後でよい

### 5位
**再生UX改善候補**
- 次話自動再生
- 連続再生時の朗読切替保持
- 朗読者固定再生
- 同一 reader のまま続けて聞く導線
- これは自動生成とは別系統なので、親チャットで都度優先度を再判定する

## 7. 今の親チャット判断
- `VOICEVOX Nemo全文生成整形MVP` は受理
- いまの active な朗読デモ導線は VOICEVOX Nemo で進める

## 8. 子チャット運用の補足
- 分野の被る子チャットがあれば、それを優先して使う
- なるべく新規子チャットを作らない
- 新規子チャットを切るのは、本当に分野が変わる時だけ
- ただし新規子チャットを切ると判断した時は、必ず前提文を付ける

---

## 9. コード差し込みの厳格ルール
- 必ず repo 実体を確認して、前後の形に厳密に合わせる
- 差し込み位置が曖昧なら、部分差し込みではなく丸ごと置換用の完成コードを優先する
- 貼り付けた時に sibling 要素の列・インデントが1つでも崩れるコードは不合格扱いにする
- JSX の兄弟要素は同じ深さなら同じ字下げで揃える
- 部分差し込みで列ズレの危険がある時は、必ず親の開始タグから閉じタグまで含めた完成ブロックを出す
- 見た目上「たまたま動くかも」で済ませず、貼る前から整形済みの完成コードを出す
