## 一般ユーザー朗読導線の現到達点
- 入口は 2 段構成
  - `/record` = 作品検索・申請・制作開始ポータル
  - `/record/create/[seriesId]` = 実制作ページ
- 入力手段は 2系統
  - ブラウザ録音
  - 既存音声ファイルアップロード
- 受け入れ形式は `mp3 / m4a / wav / webm / ogg / aac / flac`
- 保存方針は 2層
  - original 保持
  - playback 正規化
- recordings は publish 時のみ接続
- same episode / same reader は上書き
- `1 episode × 1 reader = 1 public recording`
- 人力朗読でも playback から timing json を作って `/read` 側へ接続
- /record は公開前提の朗読管理トップUIへ更新済み
- /record/create は公開向け制作UIへ更新済み

## 子チャット運用メモ
- 分野の被る子チャットがあれば、それを優先して使う
- なるべく新規子チャットを作らない
- 今回の統合報告以後、子17内の旧差分管理は終了扱いにする
- 次差分が制作 / 保存 / 同期 / recordings 周辺なら子17続投向き
- 次差分がホーム / 公開導線全体 / 初期集客 / 外向き印象なら別子チャットへ再分岐してよい
- 実ファイルの実際のコード位置・実インデント・前後文脈を確認してから、そのまま貼り付けられる完成コードを出す
- 説明用に左へ寄せたコードは出さない

## コード差し込みルール
- 実ファイルの該当箇所を確認してから、その位置にそのまま貼れる字下げで出す
- 差し込み位置が危険なら丸ごと置換用コードを優先する
- sibling の列・インデントが崩れるコードは不合格
