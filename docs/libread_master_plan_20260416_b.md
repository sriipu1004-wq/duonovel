## サンプル作品整理の固定方針
- 投稿主体
  - 全サンプル作品は LIB read 公式アカウント投稿で統一
- 原作者の見せ方
  - 公開面で別ラベル表示しない
  - タイトルに作者名を含める
  - タグにも作者タグを入れる
- タイトル規則
  - 単作は `作品名・作者名`
  - 短編集は `作者名・短編`
- タグ規則
  - 作者タグを必須化
  - 必要に応じて補助タグも付与
  - 作者名タグの表記ゆれは禁止
