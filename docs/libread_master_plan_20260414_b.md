## 朗読状態表示・自動朗読修正の現到達点
- `/works` と `/read` で NEMO 自動朗読状態の visible 表示を追加
  - 自動朗読停止
  - 自動朗読未設定
  - 自動朗読生成待ち
  - 自動朗読生成中
  - 自動朗読生成済み
- `/read` では朗読者未選択時に先頭録音へフォールバックせず、朗読停止状態へ整理
- `EpisodePlayback` は `stopNarrationByDefault` を受けて初期停止できる構成へ整理
- 作品ページ作者付近に、選択中朗読者がいる時だけ `選択中朗読者: ...` を表示
- `ContinueReadingEpisodeList` に reader availability を追加し、選択中朗読者の各話について `朗読あり / 朗読なし` を表示
- NEMO 本文前処理で、`｜漢字《よみ》` と `漢字《よみ》` を読み側だけ残すよう修正し、ルビ二重読みを抑止

## 子チャット運用メモ
- 分野の被る子チャットがあれば、それを優先して使う
- なるべく新規子チャットを作らない
- 子17を次に使う場合は、重いため「新しく作り直した子17」として扱う
- 次差分が作品サンプル整理・公開導線の見せ方寄りなので、録音制作中心の子17ではなく新しい子チャットに切ってよい
- 実ファイルの実際のコード位置・実インデント・前後文脈を確認してから、そのまま貼り付けられる完成コードを出す
- 説明用に左へ寄せたコードは出さない

## コード差し込みルール
- 実ファイルの該当箇所を確認してから、その位置にそのまま貼れる字下げで出す
- 差し込み位置が危険なら丸ごと置換用コードを優先する
- sibling の列・インデントが崩れるコードは不合格
