## 初期公開時点の朗読公開方針
- 一般朗読者が朗読投稿できる対象は、初期公開では **著作権切れ作品** に限定する
- 権利状態が曖昧な作品、第三者の権利処理が未確認な作品は、初期公開の朗読投稿対象にしない
- 作品の保護期間は日本では原則として著作者の死後70年で、期間満了後は自由利用できる共有財産として扱われるという文化庁の説明を前提に、公開対象の選定を進める citeturn732997search0turn732997search1

## 追加した優先タスク
### 1. 著作権切れ作品向け朗読投稿開放MVP
- 初期公開時点で、朗読投稿可能作品を著作権切れ作品へ限定して開放する
- 必要なこと
  - どの作品が朗読投稿可能か公開面で分かる表示
  - `/record` や作品ページでの対象制御
  - 対象外作品では朗読開始導線を出さない、または明示的に止める
  - 公開サンプル作品との整合

### 2. 朗読投稿規約・同意導線MVP
- 朗読投稿前に、少なくとも次へ同意させる
  - 投稿者本人が投稿音声について必要な権利を持つこと
  - 初期公開では著作権切れ作品のみ朗読投稿可能であること
  - 音声、表示名、プロフィール情報、朗読コメント等がサイト上で公開されうること
  - 運営が配信用・再生用に音声を保存・変換・配信すること
  - 権利侵害、なりすまし、第三者音声の無断投稿、個人情報・機密情報の混入を禁止すること
  - 違反時の非公開化・削除・利用停止の可能性
- 個人情報や保有個人データに関する公表事項、本人請求への手続などは個人情報保護委員会の整理に沿ってページ設計を確認する citeturn732997search2turn732997search4turn732997search5

### 3. 公開直前 全体最終確認MVP
- 公開直前に、最低でも次を横断確認する
  - ホーム
  - 検索
  - 作品ページ
  - 読むページ
  - 朗読管理トップ
  - 朗読制作ページ
  - 利用規約 / プライバシー / contact / FAQ / guide / status / news
  - 朗読投稿規約・同意導線
  - 著作権切れ作品のみ朗読可能になっているか
  - route制限
  - 主要ブラウザ / スマホ
  - 録音 / アップロード / 再生 / reader選択 / 停止状態

## 子チャット運用メモ
- 分野の被る子チャットがあれば、それを優先して使う
- なるべく新規子チャットを作らない
- 次差分は公開面の見せ方整理なので、新しい子チャットへ切ってよい
- 朗読投稿規約・同意導線は法務・公開導線系の子チャットで扱うのが自然
- 実ファイルの実際のコード位置・実インデント・前後文脈を確認してから、そのまま貼り付けられる完成コードを出す
- 説明用に左へ寄せたコードは出さない

## コード差し込みルール
- 実ファイルの該当箇所を確認してから、その位置にそのまま貼れる字下げで出す
- 差し込み位置が危険なら丸ごと置換用コードを優先する
- sibling の列・インデントが崩れるコードは不合格
