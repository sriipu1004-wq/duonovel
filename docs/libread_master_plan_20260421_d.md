## 次に着手するタスク
### `公開実運用仕上げMVP`
目的:
- もう一度全体を仕上げる
- 実際に不特定多数へ見せる状態かを確認する
- 一般ログインユーザーが著作権切れ作品で朗読発信できる状態かを確認する
- 足りないものがあれば、最小修正で塞ぐ

最低限含めること:
- 公開URL / 外部閲覧前提での最終導線確認
- 未ログイン閲覧、ログイン、新規登録、確認メール後導線の実確認
- 一般ユーザーでの朗読投稿導線の実確認
- 著作権切れ作品で録音 / アップロード / publish まで通るか確認
- route 制限、法務導線、広告受け皿、公開プロフィール、作品ページ、読むページの横断確認
- blocker と minor の切り分け
