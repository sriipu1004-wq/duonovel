## 2. 現在の固定方針

### 2-1. 作者向け導線
- 作者向け主導線は **作品ワークスペース中心**
- 現在の整理:
  - `/write` = 作品ワークスペース一覧
  - `/write/series/[seriesId]` = 作品ワークスペース本体
  - `/manage` = backward 互換 redirect
  - `/manage/series/[seriesId]` = backward 互換 redirect
- 管理トップは軽い入口として扱い、作品ごとの実作業は作品ワークスペースへ寄せる

### 2-2. 本文編集ページ
- `WriteEpisodeForm.tsx` は **本文編集中心**
- 本文編集ページに設定を詰め込みすぎない
- 作品全体の方向付けは作品ワークスペース側で持つ
- 本文だけスクロールしやすい構造を維持する

### 2-3. 朗読導線
- 朗読の主導線は **`/record`**
- 作品ページでは朗読可否表示は残すが、申請や制作開始の主動線は `/record` に集約
- 朗読許可状態:
  - `open`
  - `closed`
  - `approval_required`

### 2-4. BGM方針
- 外部持ち込みBGM前提では進めない
- サイト用意BGM中心
- `bgm_library` を素材正史とする
- 既存 read 側互換のため、当面は `bgm_title / bgm_audio_path / bgm_settings` 併用
- BGM素材ページは **ユーザー向け公開素材ライブラリ + 自分専用の素材投入・管理基盤** として育てる
- BGM素材追加は **運営側のみ**、一般ユーザーは不可

### 2-5. 作者ページ / マイページ
- 公開面 = `/authors/[authorId]`
- 本人面 = `/mypage`
- 完全統合ではなく、土台共通化 + 公開面 / 本人面 分離
- `/mypage` は活動ハブ
- 新規作品作成の主導線は `/write`

### 2-6. 反応機能の切り分け
- ブックマーク = 保存
- 応援 = 軽い反応
- レビュー = 言葉の反応
- それぞれ別機能として育てる

演出は以下の地点から入れるようにしたい:
- 新規小説作成時
- 次話投稿時
- 作品ワークスペース

対象演出として想定しているもの:
- BGM
- 場面転換にてBGM変更

- 文字振動
- 文字動作（キーボード打ち込み、フェードアウト等）
- 文字フォント変更
- 文字色変え
- 太字
- 文字斜線
- 文字点強調
- 文字線強調
- 背景変更（紙調、ガラス調、プラスチック調、石調、木材調）
- 挿絵

補足:
- 今後増える前提
- 設定だけでなく **演出付き本文のプレビュー** が必要

## 5. 今回追加で固定した改善点

### 5-1. BGM管理ページの整理
- 現在の BGM管理画面は、将来的に **演出基本ページ** の役割へ寄せる
- 管理トップ / 管理ハブ表示のままではなく、
  - 作品ワークスペース一覧へ
  - ワークスペースへ戻る
  表現へ寄せる
- 現在の BGM管理画面で持つべきものは、まず **作品共通デフォルト演出** に絞る
  - 共通BGM
  - フォント種類
  - 文字サイズ
  - 文字間隔
  - ルビのデフォルトサイズ
  - 共通背景
  - 思いついたら適宜追加
- それ以外は一旦削る方向

### 5-2. 演出編集ページの具体仕様
- ページ上部あたりに、そのエピソード本文を表示する
- 文字指定演出では
  - 左クリック / 長押しで青線を引いて対象文字を指定
  - リアルタイムで対象文字列として扱う
- 配置が必要なもの
  - 場面転換
  - 背景
  - 挿絵
  などは、**指定行数** により場所を指定
- 行数表示が必要
- 表示予定本文とプレビューは同じ位置に置く
  - デフォルトは本文
  - ボタン1つでプレビューに切替
  - プレビューは仮保存も表示

### 5-3. 演出編集の仮保存ルール
- 背景、既定文字は頻繁に触らない
- 文字演出、挿絵、場面転換などは繰り返し編集しやすくしたい
- そのため、各エフェクト設定に **そのエフェクト単位の仮保存ボタン** を設ける
- 現在どの演出がかかっているかは別の場所に箇条書きで管理
- その一覧には
  - 保存済み / 仮保存
  - クリック時に、どこを演出したものかプレビュー表示
  を持たせる

### 5-4. 背景仕様
- 背景は **紙をメイン** に扱う
- 様々な紙素材を用意し、設定した背景を指定行数分つないでいく形を想定
- 背景色は運営側で変更できるようにする
- 色指定はパレット形式 + 最後尾の虹色から詳細カラー指定

### 5-5. フォント / 色仕様
- フォントも背景同様に色指定可能
- 背景色指定とは別管理
- フォント変更は、使えるフォント素材を集めて一覧から選ぶ方向

### 5-6. 文字演出仕様
- 文字指定は青線で選択した対象文字列ベース
- 種類:
  - 振動
  - 表示
  - その他追加予定
- 変更対象:
  - フォント変更
  - 色変更
  - 太字
  - 斜線
  - 点強調
  - 線強調
  - その他見た目変更
- 振動:
  - 震え方のプリセット
  - 速さ
  - 強さ
- 表示:
  - 一文字ずつ表示
  - すぐ表示
  - フェードイン
  - 書き順に沿って一パーツずつ表示
  - フェードアウトで非表示
  - 表示速度

### 5-7. 挿絵仕様
- 画像をドラッグして保存する場所
- 大きさ指定
- キャプション
- 配置
- 配置は指定行数などで細かく置く前提

### 5-8. BGM場面転換仕様
- エピソード単体BGMと統合して扱う
- 1話通しで同一BGMなら、そのBGMだけ指定
- 転換がある場合:
  - 転換位置
  - 転換後BGM
  - 転換時の切り方
  - 転換時の入り方
  を指定
- 演出編集ページで強弱が必要な設定は、演出基本ページのデフォルトを参照する

### 5-9. 合成音声自動朗読機能
- 朗読許可のある作品に、自動で合成音声朗読を付ける機能を将来追加予定
- 初期は TTS
- クラファン後は voicepark の利用を想定

### 5-10. BGM素材ページの管理要件
- 自分だけが BGM素材を追加できる

- 公開 / 非公開

### 5-11. BGM素材のお気に入り

### 5-12. 朗読ページ検索UI強化

## 8. GitHub / local 同期ルール

- GitHub にあるだけで local に無い状態は、正史確認には使えても実作業継続前提にはしない
- 次の作業前に必ず local を同期する
- 用語を分ける:
  - repo正史反映済み
  - local反映済み
  - 両方反映済み
- 「反映済み」は原則、GitHub と local の両方が揃った時だけ使う

## 9. 子チャット運用ルール

- 既に担当が近い子チャットがあるなら、まずそれを優先
- 新規子チャットは
  - 担当範囲が明確に別
  - 現チャットが重い
  - 正式に切り分けた方が管理しやすい
場合だけ
- 正式報告前に最低限確認すること:
  - 現在ブランチ
  - `git status`
  - `git rev-parse HEAD`
  - `git rev-parse origin/main`
  - 必要なら `git fetch origin`
  - 必要なら `git pull --ff-only origin main`
