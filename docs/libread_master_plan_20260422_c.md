## 現時点の公開判断
### 不特定多数へ見せる状態か
- `進行可`
- 公開面、検索、作品、読む、プロフィール、案内ページ、認証導線は main 反映済み
- route 制限は既導入で、内部 route は一般ユーザーへ閉じたまま運用可能

### 一般ログインユーザーが朗読発信できる状態か
- `人力朗読は進行可`
- 一般ログインユーザーが朗読開放対象作品で録音 / アップロード / publish する導線は進行可
- 朗読名義は現在のユーザー名固定
- ただし自動朗読更新は `libread08@gmail.com` 限定

## 次に着手するタスク
### `本番公開開始MVP`
目的:
- 実際に本番URLを出し、不特定多数へ公開を開始する
- 本番公開直後に最低限の主要導線確認を行う
- blocker があれば最小修正する

最低限含めること:
- 本番デプロイ状態と本番URLの最終確認
- 未ログイン主要導線確認
- 新規登録 / 確認メール / ログイン確認
- 一般ユーザー朗読投稿確認
- 公開直後の初動監視観点整理
- blocker と minor の切り分け
