## 1. 今回追加で固定する反応機能要望

### 1-1. レビューへのいいね
- **レビューに対していいね** を付けられるようにする
- レビュー一覧は、少なくとも次の並び替えを持てるようにする
  - 投稿順
  - いいね順
- それぞれに
  - 降順
  - 昇順
  を持たせる
- レビュー欄は **タップで開閉** する形を基本にする

補足:
- 今回のユーザー文面中の「いい音」は、文脈上 **いいね** の誤記として扱う

### 1-2. エピソードごとの感想投稿フォーム
- **各エピソード末尾** に、エピソードごとの感想投稿フォームを置く
- そのフォームから投稿された内容は、**そのエピソード専用のコメント欄** に追加される
- コメント欄は **タップで開閉** する形を基本にする
- コメント欄は **エピソードごとに独立** して持つ

### 1-3. エピソードコメントへのいいね
- エピソードコメントには **1ユーザー1回まで** いいねできるようにする
- コメント欄は、少なくとも次の並び替えを持てるようにする
  - 投稿順
  - いいね順
- それぞれに
  - 降順
  - 昇順
  を持たせる

### 1-4. 作者による表示制御
- **コメント欄** は、作者の意向で非表示にできるようにする
- **レビュー欄** も、作者の意向で非表示にできるようにする
- 表示可否は、作品単位または必要に応じて話単位で持てる余地を残す
- まずは MVP として、少なくとも作者側で ON / OFF を制御できる形を優先する

## 2. 反応機能の正式整理への追加反映

`docs/libread_master_plan.md` にある反応機能の正式整理は、今後次まで含むものとして扱う。

- ブックマーク = 保存
- いいね = 軽い反応 / 人気度の簡易指標
- レビュー = 作品に対する言葉の反応
- エピソード感想 / コメント = 各話末尾で扱う言葉の反応
- レビューいいね = レビューに対する軽い反応
- コメントいいね = エピソードコメントに対する軽い反応

補足:
- 作品レビューと、エピソード末尾コメントは別物として扱う
- UI とデータ構造の両方で、作品単位とエピソード単位を混同しない

## 3. 今後の実装方針メモ

### 3-1. エピソード末尾コメント
- エピソード本文の末尾に感想投稿フォームを置く
- コメント欄はタップで開閉
- 表示時にそのエピソードのコメントだけを読む
- 並び替え:
  - 投稿順 / いいね順
  - 昇順 / 降順

### 3-2. レビュー欄
- 作品レビュー欄もタップで開閉
- 並び替え:
  - 投稿順 / いいね順
  - 昇順 / 降順
- レビューごとにいいね可能

### 3-3. 表示制御
- 作者設定で
  - レビュー表示
  - エピソードコメント表示
  を切り替えられるようにする
- まずは保存先と UI 導線の最小版を優先し、細かい粒度は後続で詰めてもよい
